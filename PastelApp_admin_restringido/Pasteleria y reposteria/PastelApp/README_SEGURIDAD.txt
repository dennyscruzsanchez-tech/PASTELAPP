ADVERTENCIA DE SEGURIDAD:
Este proyecto es frontend y la comprobación de credenciales ocurre en
JavaScript del navegador. Esto sirve para una maqueta/proyecto académico,
pero NO es una autenticación segura para producción. Para un sistema real,
usa Firebase Authentication o un backend y reglas de autorización.
